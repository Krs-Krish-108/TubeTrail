YouTube Transcript Agent

Add one video or a list of videos. The app retrieves available captions directly from YouTube and saves them as text files. Add a #name line under a link to set its filename.

Put #name Your file name on the line just below a link. Use one link per line. The name is used for the saved .txt file; if you leave it out, the app will ask you. Only videos with captions can produce a transcript.
